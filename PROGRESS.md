# Progress

How much of `WW.EXE` is rebuilt from C. Generated by `tools/progress.py` (do not edit by hand),
measured at commit `7290da0`.

**198 of the game's 285 C functions compile to the original's exact bytes (69.5%).**

A function counts only when our build of `src/ww.c` (Watcom C 9.5b, `-s -3r -oneatx`) gives
the same bytes as the game at the same address, with every address it refers to checked as
well. A near miss behaves the same as far as we know, but its code still differs: the number
is how many instructions differ (`tools/wc/fndiff.py`).

To search and filter the functions and see each near miss's diff, open
[`docs/WWPROGRESS.HTML`](docs/WWPROGRESS.HTML) in a browser.
